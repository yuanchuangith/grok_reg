## 已完成功能

### Web 控制台

- macOS 风格可视化管理界面。
- 密码访问控制。
- 邮箱凭证导入、搜索、删除和使用状态管理。
- 成功账户、失败记录、CPA 凭证和任务日志管理。
- 配置中心按模块切换，代理网络使用独立页面。

### 注册与 CPA

- 注册任务和缺失 CPA 批量补全。
- 成功邮箱去重，已经注册成功的邮箱不会再次分配。
- 服务端 Chromium 原生点击和输入兼容处理。
- CPA 模型探测日志已改为明确的中文成功或失败状态。
- 已有 CPA 的账户提供“刷新凭证”按钮。
- 凭证刷新优先使用 refresh_token，通过验证后原子替换旧文件。
- refresh_token 失败时自动进入完整 SSO/OIDC 重取流程。
- 新凭证验证失败时保留或恢复旧凭证文件。

### 代理网络

- Clash 多订阅分组代理池。
- 带账户密码的静态代理池。
- 两种代理模式互斥，关闭总开关时普通任务可直连。
- 支持手动选择、跨组随机、节点测活和故障切换。
- Web 服务与注册子进程可复用同一 Mihomo 实例。

### 模型与额度状态

- 成功账户可以展示可用模型 Tag。
- 支持刷新模型列表、点击模型 Tag 单独测试。
- 支持刷新账户的模型额度状态，并读取可用的限流响应头。
- 模型、测试和额度接口强制走代理；代理关闭时拒绝请求。
- 代理瞬时网络失败会重新选择节点并最多重试三次。
- 最近模型和测试结果保存在 CPA 目录的隐藏缓存中，不写入导出的凭证 JSON。
