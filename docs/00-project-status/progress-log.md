## 2026-07-13 失效 CPA 凭证安全刷新

- 成功账户增加“刷新凭证”按钮和操作确认。
- 增加 refresh_token 无浏览器快速刷新流程，所有刷新请求使用当前代理配置。

- 线上真实账户 refresh_token 刷新成功，刷新后 `grok-4.5` 请求返回 HTTP 200。
