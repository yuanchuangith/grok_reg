# REQ-20260713-001 成功账户模型与额度状态管理

## 基本信息

- 状态：已完成
- 创建日期：2026-07-13
- 提出来源：用户
- 对应变更：CHG-20260713-001

## 背景

成功账户已有 CPA 凭证，但账户列表无法直接看出凭证支持哪些模型，也缺少重新获取模型列表、单独测试模型和更新当前额度状态的操作。

## 需求内容

1. 每个成功账户展示可用模型 Tag。
2. 模型 Tag 可以反映未测试、可用或受限状态。
3. 可以重新获取账户的最新模型列表。
4. 可以点击某个模型进行最小请求测试。
5. 可以刷新账户下全部模型的额度或限流状态。
6. Grok 模型相关请求必须使用代理，禁止直连。
7. 代理出现瞬时网络错误时应自动切换或重试。

## 范围

### 包含

- 成功账户列表界面。
- CPA 模型列表接口。
- Responses 最小模型测试。
- 限流响应头展示。
- 模型与测试结果缓存。

### 不包含

- 增加或绕过 xAI 上游额度。
- 没有 CPA 凭证时查询模型。
- 完整的历史趋势图表。
- OAuth access token 自动刷新。

## 验收标准

1. 有 CPA 的账户可以点击“获取模型”或“刷新模型”。
2. 返回的模型以 Tag 展示，点击 Tag 可以测试该模型。
3. 测试成功显示绿色状态，受限或失败显示红色状态。
4. 如果响应包含额度或重试信息，应在 Tag 中展示。
5. “刷新额度状态”可以测试账户下全部已知模型。
6. 代理未开启时接口拒绝执行，并提示先开启代理。
7. 瞬时网络失败最多自动重试三次。

## 约束与风险

- 共享 Mihomo 出口可能限制真正的多账户并行测试。
- 上游不一定返回数字额度响应头，此时只能展示可用或受限状态。
- access token 过期时需要后续增加刷新机制。
